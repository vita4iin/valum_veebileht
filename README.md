# valum_veebileht

### Esialgne info veebilehe kohta
#### Eesmärk. "Padel Tartus" on algaja juhend padeli mängimiseks Tartus. Leht vastab kolmele küsimusele: mis on padel, kus Tartus mängida ja kuidas mängida.
##### Sisu ja ülesehitus. Kolm lehte ühise päise (logo, navigatsioon) ja jalusega:
1. Avaleht – padeli tutvustus, pildikarussell (JS), video, viited alalehtedele
2. Kus mängida – Tartu väljakud koos aadressi, väljakute arvu ja broneerimislingiga, filter sise/välis (JS), kaart
3. Õpi mängima – reeglid, punktiarvestus, interaktiivne skooriloendur (JS), põhilöögid, varustus
